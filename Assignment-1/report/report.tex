\section{Cách build và chạy lại}
Mã nguồn cần compiler C++20 (Apple clang, g++ hoặc clang++), \texttt{make} và Python~3. Phần vẽ hình
cần thêm \texttt{matplotlib} và \texttt{numpy}. Báo cáo biên dịch bằng XeLaTeX (TeX Live). Chi tiết
trong \texttt{README.md}.

\begin{lstlisting}[language=bash]
make                 # biên dịch các bài kiểm tra và các benchmark vào build/
make test            # chạy mọi bài kiểm tra tính đúng đắn
make tsan            # chạy lại dưới ThreadSanitizer
make mutation        # các biến thể cố ý làm hỏng phải bị bộ kiểm tra bắt
make check           # bốn lệnh trên, theo thứ tự
make bench          # chạy toàn bộ đợt đo trên máy rảnh -> results/<máy>/
make figures         # vẽ lại mọi hình và bảng từ results/ -> report/figures/
make report          # biên dịch report/report.pdf
make zip             # đóng gói bài nộp
make full            # cả quy trình: check, bench, figures, report, zip
\end{lstlisting}
